# 普通用户指南

## 登录与个人资料

可以使用本地账号，或由管理员启用的 GitCode OAuth。姓名、工号和邮箱会在提交工单时复制为审计快照；修改邮箱需要 6 位验证码，验证码 10 分钟有效且最多尝试 5 次。

## 申请类型

| 类型 | 用途 |
|------|------|
| 申请服务器账号 | 以当前平台用户名在目标机创建普通账号并加入 `nrm_managed` |
| 转移已有账号 | 填写本人已有的 Linux 用户名，将其纳入 NRM 管理 |
| 申请用户组 | 为已有机器用户申请 `sudo` 或 `docker` 组 |
| 申请平台管理员 | 为已有机器用户申请 sudo 管理能力 |

`sudo`、`docker` 和平台管理员均具备 root 等价能力，只能由超级管理员批准。

## 工单结果

- 待审批：可以撤回。
- 已驳回：详情页显示审批意见。
- 已通过且开通完成：申请人可在禁止缓存的详情页查看初始密码；目标机首次登录会强制改密。
- 已通过但机器操作失败：详情页显示失败原因，由有审批权的管理员修复后重试。

初始密码也可发送到工单中的邮箱。请在首次登录后立即修改，不要通过聊天工具转发。
