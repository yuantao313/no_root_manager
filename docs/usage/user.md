# 普通用户指南

## 注册与登录

1. 打开系统首页，点击「注册」，填写用户名与密码即可完成注册（注册后自动登录）。
2. 已有账号直接「登录」。
3. 也支持使用 GitCode 账号登录：
   - 首次使用 GitCode 登录时，选择「创建新账号」注册，或「绑定已有账号」把 GitCode 关联到现有账号；
   - 之后可直接用 GitCode 一键登录。

## 提交申请

登录后进入「我的申请」页面，左侧填写申请，右侧查看进度：

1. **选择申请类型**：
   - **申请服务器账号**：在目标机器上为你创建新账号（目标机器用户名按你的姓名自动生成，无需手填）。
   - **转移已有账号为受管用户**：你已在该机器上有一个账号，把它纳入统一管理——需填写目标机器上已有的用户名。
2. 选择**目标服务器**（仅 NPU 服务器会显示可选授权使用的 NPU 卡组）。
3. 填写**申请理由**；可选设置**使用截止时间**、勾选**申请 sudo 权限**（当天有效）。
4. 点击「提交申请」，等待管理员审批。

## 查看申请进度

「我的申请」右侧列表显示每条申请的状态：

| 状态 | 含义 |
|------|------|
| 待审批 | 管理员尚未处理；可点击「撤回」取消该申请 |
| 已通过 | 账号已开通（密码通过邮件发送到你的邮箱） |
| 已驳回 | 查看审批意见后可修改后重新提交 |
| 已撤回 | 你在待审批时主动撤回的申请 |

## 维护个人资料

「个人中心」可修改：

- **姓名**：申请开通时目标机器用户名按姓名自动生成，请确保姓名准确。
- **工号**：随申请自动带入。
- **邮箱**：用于接收开通密码与审批通知。修改邮箱需先「发送验证码」到新邮箱，填写验证码后才能保存（60 秒内不可重复发送）。
- **密码**：可设置或修改本地密码。

## 与 GitCode 绑定

- 未绑定：在个人中心点「绑定 GitCode」，授权后完成绑定。
- 已绑定：个人中心显示绑定的 GitCode 账号，可解绑（仅通过 GitCode 登录的用户，解绑前需先设置本地密码）。
