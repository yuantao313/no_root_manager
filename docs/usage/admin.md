# 管理员指南

管理员负责**审批用户提交的申请**。管理员只能审批自己有权管理的服务器上的申请。

## 审批申请

1. 登录后进入「申请列表」，查看待审批的申请。
2. 点击「查看」进入申请详情，可见：申请人、申请类型、目标服务器、申请理由、NPU 卡组、sudo 权限、使用截止时间等。
3. 处理申请：
   - **通过**：系统自动在目标机器上执行开通——
     - 申请服务器账号：创建用户、生成随机密码（邮件发送给申请人）、写入资源限制；
     - 转移已有账号：把机器上已有账号纳入统一管理并绑定到申请人；
     - 若勾选了 sudo：授予 sudo 权限（当天有效，次日自动失效）。
   - **驳回**：填写驳回意见，申请人可在「我的申请」中看到。
4. 已处理的申请不能重复审批。

## 注意事项

- 申请开通需要目标服务器已关联可用的管理凭据，否则会提示"未关联目标服务器或凭据"。
- 审批通过后可在申请详情查看开通结果（provision_note）与 sudo 授权记录。
