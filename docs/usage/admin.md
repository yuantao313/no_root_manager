# 普通管理员指南

普通管理员只负责审批超级管理员已绑定给自己的服务器，不可查看或修改服务器凭据、系统设置和其他服务器。

## 审批

1. 在“申请列表”按状态、类型或服务器筛选。
2. 打开详情，核对申请人快照、机器用户名、申请类型、服务器和理由。
3. 通过普通账号创建或接管申请，或填写原因后驳回。
4. 审批通过时页面会等待 SSH 操作完成并直接反馈结果。
5. 若工单已通过但机器操作失败，修复连接问题后可在详情页重试。

普通管理员不能批准 `sudo`、`docker`、平台管理员或服务器默认组中包含 root 等价组的申请。无权访问的工单返回 404，角色级无权页面返回 403。

## 审批前置条件

- 目标服务器已关联凭据。
- SSH 主机指纹已经超级管理员核验。
- 管理凭据可连接，并具备 root 或 `sudo -n` 权限。

通知失败不影响审批或开通结果；需要结合应用日志确认邮件/Webhook 是否送达。
