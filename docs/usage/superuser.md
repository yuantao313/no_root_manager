# 超级管理员指南

超级管理员拥有全部工单审批权，并负责服务器、凭据、系统设置和用户角色。

## 接入服务器

1. 在 Django Admin 的“凭据”中创建只写密码或私钥。
2. 在“服务器”中新建记录并关联凭据。
3. 获取候选 SSH 指纹，通过目标机控制台或其他可信渠道核对后录入。
4. 保存并测试连接，再执行基础初始化。

服务器详情提供 CPU/内存/磁盘概览、受管用户、可接管用户、锁定/解锁和附加组调整。设备概览是按需查询，不是持续监控。

## 权限管理

- 用户的 `is_staff` / `is_superuser` 通过 Django Admin 管理。
- 普通管理员与服务器的绑定在“系统设置”中维护。
- `sudo`、`wheel`、`docker` 均按 root 等价权限处理，只能由超级管理员批准。
- NRM 当前不提供临时 sudo、到期自动撤权或资源配额。

## 系统设置

- GitCode：启用开关、OAuth Client ID/Secret 和回调基准地址。
- 邮件：SMTP 或邮件 Webhook 二选一；SMTP 保存前必须完成验证码验证。
- Webhook：全局 Hook 接收全部申请事件，管理员个人 Hook 只接收有权审批的事件。
- 公告：受控 Markdown 子集在平台首页展示，并可推送到目标机 motd。

所有 Webhook 只允许公网 HTTPS。秘密字段编辑时不回显，留空表示保留原值。

## 删除数据

工单是审计记录：删除用户后工单仍保留申请人快照。删除服务器后工单的目标服务器引用置空；正在被服务器引用的凭据受 `PROTECT` 保护，必须先解除引用。
