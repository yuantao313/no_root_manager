# 超级管理员指南

超级管理员拥有全部权限：服务器、凭据、系统设置、用户管理与审批。以下操作仅超级管理员可见。

## 服务器管理

「服务器」列表可**新增/编辑/删除**服务器（名称、地址、端口、关联凭据）。

进入服务器详情，可对目标机器上的用户进行管理：

- **同步**：同步机器上 `nrm_managed` 组成员到系统，并采集各用户的**资源使用**（磁盘、内存、CPU），面板右上角显示上次同步时间。
- **受管用户**：每个受管用户显示绑定账号、磁盘/内存/CPU 占用，可一键**禁用/启用**（passwd -l/-u）。
- **可接管用户**：列出机器上 `/home` 下未纳入管理的用户，选择绑定的系统账号后点击「接管」，把已有用户纳入统一管理。
- **测试连接**：验证 SSH 连接是否可用。

## 凭据管理

「凭据」列表可新增/查看/删除服务器的登录凭据（用户名 + 密码或私钥，加密存储）。

- 删除凭据前，若该凭据正被服务器使用，系统会提示关联的服务器数量，需先到服务器管理中解除引用。

## 系统设置

「系统设置」包含四个页签：

### GitCode 登录
- 填写 GitCode OAuth 的 Client ID / Client Secret。
- 页面会展示**回调地址**（如 `https://你的域名/accounts/allauth/gitcode/login/callback/`），请到 GitCode 应用管理页配置为完全一致的值。

### 邮件通知
- 填写 SMTP 服务器、端口、用户名、密码/授权码、发件人地址。
- 勾选「使用 SSL 直连（465 端口）」：465 端口用 SSL，587/25 端口取消勾选。
- 保存流程：填写配置 + 验证收件邮箱 → 「发送验证码」（60 秒冷却）→ 填验证码点「验证」→ 验证通过后「保存配置」才可点击。
- 开启「启用邮件通知」后，系统通过该邮箱发送新申请、审批结果、开通密码等通知。

### 全局 Webhook
- 添加 Webhook 地址，申请创建/审批事件会推送通知。

### 管理员与服务器绑定
- 为普通管理员分配可审批的服务器；超级管理员默认可管理全部服务器。

## 用户管理

管理员账号的角色（普通管理员/超级管理员）在**后台管理**（Django Admin）中设置：进入后台 → 用户列表 → 编辑用户 → 勾选「工作人员状态」（管理员）/「超级用户状态」（超级管理员）。

## 审批

超级管理员可审批全部服务器的申请（操作同管理员指南）。
