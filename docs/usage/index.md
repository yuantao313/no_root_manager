# 使用指南

NRM 提供三类角色，登录后进入不同的操作界面：

| 角色 | 你能做什么 |
|------|-----------|
| **普通用户** | 提交申请、查看自己的申请进度、维护个人资料 |
| **管理员** | 审批绑定服务器的申请 |
| **超级管理员** | 管理服务器/凭据、审批全部申请、维护系统设置 |

- [普通用户](user.md)：注册、登录、提交申请、查看进度、个人资料
- [管理员](admin.md)：审批申请
- [超级管理员](superuser.md)：服务器、凭据、系统设置、用户管理

> 管理员与普通用户使用同一登录系统，角色由超级管理员在后台（Django Admin）设置。
